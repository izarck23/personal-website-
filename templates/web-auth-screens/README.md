# Modern Web Authentication Screens & Gateway Suite

> **Production Multi-Screen Auth Gateway**  
> **Tech Stack:** Semantic HTML5 • CSS3 (Concentric Waves & Glassmorphism) • Vanilla JavaScript (ES6+) • Node.js / Express REST API (Full-Stack Edition)

---

## 🌟 Overview
A clean, soft-modern authentication UI featuring concentric circular wave gradients, pastel coral/purple accents, and full multi-screen routing (Welcome, Sign In, Sign Up, 2FA Verification, and Password Reset).

## 🚀 Features Review
1. **Concentric Radial Wave Aesthetic**: Soft pastel background geometry with layered concentric rings and ambient blurred lighting.
2. **5 Integrated Authentication Screens**:
   - `Welcome (=)`: Entry screen with direct dual routing.
   - `Welcome Back (Sign In)`: Email & password with eye visibility toggle, remember me, and social OAuth simulation.
   - `Create Account (Sign Up)`: Full name, email, password strength indicator, terms confirmation.
   - `2FA (OTP Verification)`: 6-digit auto-advancing verification code boxes with backspace navigation and resend cooldown.
   - `Password Recovery`: Email reset link dispatch with status toast.
3. **Password Strength Meter**: Dynamic color-coded bar (Red/Orange/Blue/Green) validating length, uppercase, numbers, and symbols.
4. **Mobile & Desktop Frame**: Centered 420px device container on desktop, fluid 100% viewport width on mobile.

---

## 💻 Tech Stack & Zero-Build Setup
- **HTML5:** Modular card structures with semantic forms and accessibility labels.
- **CSS3:** Radial gradients, cubic-bezier transition curves, and CSS custom variables.
- **JavaScript:** Pure Vanilla DOM manipulation with 0 npm dependencies required.
- **Node.js / Express Backend (Premium Edition - $1.99)**: JWT authentication tokens, bcrypt password hashing, auth routes (`/api/auth/register`, `/api/auth/login`, `/api/auth/verify-otp`, `/api/auth/forgot-password`), controllers, and `.env` setup.

## 🛠️ Quick Start
1. Unzip the downloaded `web-authentication-screens-frontend.zip` archive.
2. Open `index.html` in your web browser or code editor.
3. Switch between screens using the interactive buttons or preview directly!
